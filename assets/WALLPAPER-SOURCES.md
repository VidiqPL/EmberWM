# Abbey wallpaper sources

Both JPEGs are downloaded originals, stored without pixel edits.

- `Abbayedansunbois.jpg`: Caspar David Friedrich, *The Abbey in the Oakwood*
  (1809–1810), 960×616, 81,823 bytes.
  [Wikimedia Commons file and public-domain statement](https://commons.wikimedia.org/wiki/File:Abbayedansunbois.jpg).
  Download: https://upload.wikimedia.org/wikipedia/commons/d/da/Abbayedansunbois.jpg
  SHA-256: `f1a1e6c6d99f76b8314267e238a00de39b94fe24dcbef7884544e6744049b70b`.
- `abbey-oakwood.jpg`: larger 3998×1673 scan/crop of the same public-domain painting,
  downloaded from [Wallhaven 8okqe2](https://wallhaven.cc/w/8okqe2).
  Its uploader cites [Google Arts & Culture](https://artsandculture.google.com/asset/abbey-among-oak-trees-caspar-david-friedrich/UAEmmuxqtNUt-g).
  Download: https://w.wallhaven.cc/full/8o/wallhaven-8okqe2.jpg
  SHA-256: `5a10727fdaa087e7a3baa258df57c4aba83aea43ec20cddc83393176306aa23e`.
